# 🌀 CoilVPN — простой VPN для игр по локальной сети

**CoilVPN** — это лёгкий кроссплатформенный VPN, созданный для того, чтобы объединить игроков в общую виртуальную сеть.  
Поддерживает **Linux** и **Windows 10/11**. Максимум — 5 устройств (можно расширить в коде сервера).

[![License: CC BY-NC 4.0](https://img.shields.io/badge/License-CC%20BY--NC%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by-nc/4.0/)
## ✨ Возможности
- Создание виртуальной сети с IP-адресами вида `10.7.0.x`
- P2P-соединение между игроками (трафик идёт напрямую)
- Автоматическое шифрование трафика
- Простой графический интерфейс на `tkinter`
- Сохранение настроек в `config.json`

---

## 📥 Требования

### Общие для всех
- Python 3.8 или новее
- Пакеты: `requests`, `cryptography`, `flask`, `pytun3` (только Windows)

### Для Linux
- Утилита `ip` из пакета `iproute2` (обычно уже установлена)
- Права `root` (для создания TUN-устройства)

### Для Windows
- Драйвер **TAP-Windows** (входит в состав OpenVPN)
- Права администратора (запуск консоли от имени администратора)

## 🚀 Установка и запуск

### 1. Скачайте проект
```bash
git clone https://github.com/Shavermushka/CoilVPN.git
cd CoilVPN
```
### 2. Установите зависимости
Linux (через venv):
```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```
Windows (открыть cmd от имени администратора):
```bash
pip install -r requirements.txt
```
>Если pip не найден, переустановите Python с галочкой «Add to PATH».

### 3. Установка драйвера TAP (только Windows)

- Скачайте [OpenVPN Community Edition](https://openvpn.net/community-downloads/)
* При установке выберите компонент TAP Virtual Ethernet Adapter
+ После установки перезагрузите компьютер

### 4. Запуск сервера (один компьютер, Linux или Windows)

Сервер нужен только для координации — он раздаёт виртуальные IP и сообщает клиентам адреса друг друга.
Его можно запустить на любом компьютере (даже на одном из игроков).
```bash
python vpn_server.py
```
Вы увидите:
```bash
 * Running on all addresses (0.0.0.0)
 * Running on http://192.168.0.107:8005
```
**Запомните IP-адрес (в примере 192.168.0.107) — он понадобится клиентам.**
>Если порт 8005 занят, измените port=8005 в последней строке vpn_server.py.

### 5. Запуск клиента (на каждом игровом ПК)
*Linux*
```bash
sudo python vpn_client.py
```
***Пароль root нужен для создания TUN-устройства.***

*Windows*
```bash
sudo venv/bin/python vpn_client.py
```
Откроется графическое окно CoilVPN Client.

### 6. Настройка клиента

| Поле | Значение | Пример |
|------|----------|--------|
| **Имя игрока** | Уникальное имя (без пробелов) | `Player1` |
| **UDP порт** | Любой свободный порт (1024–65535) | `5000` |
| **Адрес сервера** | IP и порт сервера координации | `http://192.168.0.107:8005` |

>Если сервер и клиент на одной машине, укажите http://127.0.0.1:8005.

Нажмите «Подключиться».
Через несколько секунд статус сменится на «Подключён», и появится ваш виртуальный IP (например, 10.7.0.10).

### 7. Проверка связи

Откройте терминал (Linux) или cmd (Windows) и выполните ping до другого участника:
```bash
ping 10.7.0.11
```
Если ответы идут — VPN работает.

🎮 Игра по локальной сети

1. Запустите игру (например, Minecraft, Warcraft III, Counter-Strike 1.6).
2. Выберите режим «Локальная сеть» или «Multiplayer» → «LAN».
3. Подключайтесь к виртуальному IP другого игрока (он виден в списке «Участники сети» в клиенте CoilVPN).

### ⚙️ Расширение возможностей

**Изменение количества устройств**
В файле vpn_server.py найдите строку:
```bash
virtual_ips = [f"10.7.0.{i}" for i in range(10, 15)]  # 5 адресов (10,11,12,13,14)
```
Измените диапазон, например *range(10, 20)* для 10 адресов.

**Смена UDP порта клиента**

Каждый клиент использует свой UDP порт для прямого общения.
Если на одной машине запущено два клиента (для теста), укажите разные порты в интерфейсе (например, *5000* и *5001*).

> [!NOTE]
> <ins>Использование через интернет:</ins>  Для игры через интернет нужен белый IP-адрес (или проброс портов) на компьютере с сервером координации.
Клиенты должны указывать публичный IP сервера.
P2P-трафик между клиентами может требовать настройки NAT (UPnP или ручной проброс). Проще всего использовать ZeroTier вместо CoilVPN для интернета.

### 🐛 Устранение неполадок

| Проблема | Решение |
|----------|---------|
| `ModuleNotFoundError: No module named 'pytun3'` (Windows) | Выполните `pip install pytun3` |
| `Ошибка создания TUN: ...` (Linux) | Запускайте клиент с `sudo` |
| `Не удалось зарегистрироваться` | Проверьте, запущен ли сервер и правильный ли IP в настройках клиента |
| `Address already in use` (сервер) | Порт 8005 занят. Убейте процесс: `sudo fuser -k 8005/tcp` |
| `Username exists` | Выберите другое имя игрока или перезапустите сервер |
| На Windows нет TAP-адаптера | Установите OpenVPN с компонентом TAP и перезагрузитесь |
| Пиры не появляются в списке | Подождите 10–20 секунд (обновление каждые 10 секунд). Проверьте файрвол: UDP-порт клиента должен быть открыт. |

**Получение логов для диагностики**

При каждом запуске клиента создаётся
файл vpn_client.log — отправьте его автору, если что-то пошло не так.
